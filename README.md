Музыкальная Студия (Java Track Manager)

Небольшой рабочий бэкенд-проект на Java, демонстрирующий базовые принципы ООП (классы, объекты, инициализацию полей и вызовы методов). 

Что делает этот проект:
* Создает модель музыкального трека ("Track") с параметрами темпа (BPM) и названия ("title").
* Эмулирует запуск трека в профессиональной цифровой аудиостанции (DAW Reaper).
* В главном классе "MetalStudio" инициализирует объект трека группы Metallica — "Master Of Puppets" на скорости 220 BPM и выводит лог воспроизведения в консоль.

Стек технологий:
* Java SE (Core)
* ООП (Объекты, методы, взаимодействие классов)

Как запустить и проверить:
1. Запустите метод "main" в классе "MetalStudio.java".
2. В консоли отобразится результат: 
   "Воспроизведение: Master Of Puppets на скорости 220 BPM. Heavy Metal!"
